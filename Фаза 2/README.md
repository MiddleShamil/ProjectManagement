## 4. Постановка задачи

Обозначения: $i$ — участник, $j$ — задача, $p_{ij}$ — предпочтительность, $t_j$ — трудоёмкость, $\bar T = 10$ ч — средняя нагрузка, $\delta = 2$ ч — допустимое отклонение. Переменные $x_{ij} \in \{0,1\}$: 1, если задача $j$ назначена участнику $i$.

$$\max \sum_i \sum_j p_{ij} x_{ij}$$

при ограничениях

$$\sum_i x_{ij} = 1 \quad \forall j \qquad \text{(у каждой задачи ровно один исполнитель)}$$

$$\bar T - \delta \le \sum_j t_j x_{ij} \le \bar T + \delta \quad \forall i \qquad \text{(баланс нагрузки)}$$

$$x_{i,T3} = x_{i,T4} \quad \forall i \qquad \text{(изучивший COSMIC сам считает CFP)}$$

Обоснование:

- **Целевая функция** — суммарная предпочтительность: люди быстрее и качественнее делают то, что хотят делать.
- **Один исполнитель** — у задачи должен быть ровно один ответственный (R в матрице RACI).
- **Баланс нагрузки** — без него оптимум по предпочтениям перегружает одного человека; трудоёмкость из покера входит в модель именно здесь. $\delta = 2$ ч — около 20 % средней нагрузки: при $\delta = 0$ точное равенство слишком жёстко для задач разной длины.
- **Связка T3–T4** — передавать подсчёт другому значило бы изучать метод дважды.

Рассмотренные альтернативные постановки: (а) минимизировать максимальную нагрузку при ограничении снизу на предпочтения; (б) свёртка «предпочтения минус штраф за разброс нагрузки» — отвергнута, потому что вес штрафа пришлось бы назначать произвольно; (в) минимизировать суммарную «нежелательность» — эквивалентна выбранной.
