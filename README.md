# Проектный менеджмент — практика

Команда: Абдуллаев Дмитрий, Хисаметдинов Мохаммед, Саввинов Дмитрий.

Проект: **EventPass** — веб-сервис записи на студенческие мероприятия с QR-билетом и чек-ином на входе.

| Папка | Содержание |
|---|---|
| [Фаза 1](Фаза%201/README.md) | Выбор концепции: нечёткий коллективный TOPSIS и чёткий коллективный МАИ. Тот же расчёт формулами — `Фаза 1.xlsx` |
| [Фаза 2](Фаза%202/README.md) | Распределение задач фазы 3: задача о назначениях с балансом нагрузки. Модель для «Поиска решения» — `Фаза 2.xlsx` |
| [Фаза 3](Фаза%203/README.md) | Use cases, COSMIC FP, Use Case Points, покер планирования, выводы |
| [Фаза 4](Фаза%204/README.md) | Прогноз срока фазы 5 методом Монте-Карло: по числу задач в неделю и по человеко-часам с треугольными оценками. Симуляция формулами — `Фаза 4.xlsx` |
| [Фаза 5](Фаза%205/README.md) | План проекта: 25 работ, ресурсы, связи предшествования, 12 эвристик приоритетов + случайные, календарный план и диаграмма Ганта. Данные и план — `Фаза 5.xlsx` |

Матрица RACI с периодами и временем — [RACI.md](RACI.md). Задачи всех фаз также ведутся в таск-трекере YouGile (доска «EventPass — практика»).
