## 4. Нечёткий коллективный TOPSIS

Шаги:

1. Нормализация. Для критериев «больше — лучше»: $\tilde r_{ij} = (l_{ij}/u_j^*,\ m_{ij}/u_j^*,\ u_{ij}/u_j^*)$, где $u_j^* = \max_i u_{ij}$. Для риска (C5): $\tilde r_{ij} = (l_j^-/u_{ij},\ l_j^-/m_{ij},\ l_j^-/l_{ij})$, где $l_j^- = \min_i l_{ij}$.
2. Веса — треугольные числа важности, делённые на 10. Взвешенная матрица: $\tilde v_{ij} = \tilde r_{ij} \otimes \tilde w_j$ (покомпонентное умножение).
3. Идеальное решение $A^*$: по каждому критерию $v_j^* = \max_i u(\tilde v_{ij})$; антиидеальное $A^-$: $v_j^- = \min_i l(\tilde v_{ij})$.
4. Расстояние между треугольными числами — вершинный метод: $d(\tilde a, \tilde b) = \sqrt{\tfrac13[(l_a-l_b)^2+(m_a-m_b)^2+(u_a-u_b)^2]}$; $d_i^*$ и $d_i^-$ — суммы расстояний по критериям.
5. Коэффициент близости $CC_i = d_i^- / (d_i^* + d_i^-)$, лучший вариант — с наибольшим $CC$.

## 5. Чёткий коллективный МАИ

Иерархия: цель (выбрать концепцию) → 5 критериев → 4 альтернативы.

Матрицы парных сравнений каждого эксперта построены из его же балльных оценок: разница в $k$ баллов переводится в оценку $k+1$ по шкале Саати (равные баллы → 1, разница 1 → 2, …, не больше 9), обратное сравнение — обратная величина. Для риска (C5) предпочтительнее вариант с меньшим баллом. Так каждый эксперт даёт 1 матрицу критериев 5×5 и 5 матриц альтернатив 4×4, и его суждения остаются согласованными с оценками, использованными в TOPSIS.

Коллективная матрица — среднее геометрическое индивидуальных суждений по каждой ячейке (сохраняет обратную симметричность). Приоритеты — главный собственный вектор; согласованность: $ИС = (\lambda_{max}-n)/(n-1)$, $ОС = ИС/СИ$ (СИ = 0,90 для $n=4$ и 1,12 для $n=5$), допустимо $ОС \le 0{,}1$.

## 6. Сравнение методов и выводы

| Альтернатива | TOPSIS, $CC$ | Место | МАИ, приоритет | Место |
|---|---|---|---|---|
| A1 EventPass | 0.594 | 1 | 0.357 | 1 |
| A2 SplitBot | 0.458 | 3 | 0.251 | 2 |
| A3 RoomBook | 0.493 | 2 | 0.230 | 3 |
| A4 HabitDuel | 0.373 | 4 | 0.162 | 4 |

- Оба метода ставят на первое место **A1 EventPass**.
- Порядок остальных альтернатив различается: 2-е и 3-е места (SplitBot и RoomBook) меняются местами. SplitBot — «контрастный» вариант: очень силён по компактности и риску, слаб по пригодности для оценки и планирования. МАИ через шкалу Саати усиливает его крупные преимущества, а TOPSIS штрафует за удалённость от идеала по слабым критериям, поэтому ровный RoomBook там выше.
- Отрыв лидера от второго места: в TOPSIS 0.101 по $CC$, в МАИ 0.106 по приоритету (в 1.42 раза). МАИ разделяет варианты резче: шкала Саати усиливает разницу в баллах, а TOPSIS работает с исходными баллами и их разбросом.
- Каждый эксперт по отдельности тоже получает того же лидера — разногласий по главному выводу нет.
- Самые весомые критерии в МАИ — C2, C3; в TOPSIS те же критерии имеют наибольшие нечёткие веса.
- TOPSIS учитывает разброс мнений через трёхточечные оценки, МАИ усредняет суждения геометрически и даёт проверку согласованности. Совпадение лидера в двух методах разной природы делает выбор устойчивым.

**Решение:** для фаз 2–5 берём концепцию **A1 EventPass** — веб-сервис записи на студенческие мероприятия с QR-билетом и чек-ином на входе.
